# "Αστέρι της Σκηνής" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a mobile-friendly React math game with 7 themed worlds, adaptive difficulty, dance mini-games, and beautiful animations — all in Greek.

**Architecture:** Single-page React app with screen-based routing via state, game context for progress, audio context for music/SFX, localStorage persistence. No backend.

**Tech Stack:** Vite, React 18, TypeScript, Framer Motion, Howler.js, CSS Modules, GitHub Pages
